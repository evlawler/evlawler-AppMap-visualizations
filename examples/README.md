# Examples

Worked, real examples — every diagram here was generated from actual AppMap recordings, not drawn by hand.

- **`whoami_admin.diff.md`** — the FINOS Waltz JWT scene. An AI coder "fixes" a hardcoded signing secret; tests stay green; every authenticated request silently flips `200 → 403`. Before: the full path (`verifyAndGetSubject → SELECT … person → 200`). After: it halts at the auth filter (`verify throws → 403`, database never reached). Generated by `bin/appmap-diff-mermaid.mjs` from the two raw recordings.
- **`whoami_admin.before-after.html`** — the same diff as a styled, self-contained page (open it in a browser): before/after side by side with the breaking step boxed, and a plain "what changed" list.

Provenance of the sample: `before` is the committed `whoami_admin` baseline (the real 200 path). `after` is the genuine invalid-signature recording (`whoami_rejected_token`) — the exact 403 path the broken build routes every authenticated request onto. In a normal run you point `after` at the re-recording of the same test on the patched branch; the picture is the same.
