What changed

  • Status200 → 403 on GET /api/user/whoami — for every already-issued token, under default config.
  • ThrowsverifyAndGetSubject now raises SignatureVerificationException; the filter converts it to a HaltException (403).
  • Not runUserEndpoint.handle never executes — the request is halted before routing.
  • Not runUserDao.findRolesByUserName → SELECT … FROM person is never reached. The database read simply disappears.
